# Vercel Environment Variables Setup

No `.env` file is needed.

In Vercel:

1. Open your project.
2. Settings → Environment Variables.
3. Add `NEWSDATA_API_KEY`.
4. Add `ADMIN_KEY`.
5. Save.
6. Redeploy.

Example variable names only:

NEWSDATA_API_KEY
ADMIN_KEY

Never commit the actual values to GitHub.
